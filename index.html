🐙 Host Free on GitHub Pages

You can host this entire web app on GitHub Pages completely free in 3 quick steps:

  1. Push this repository to your GitHub account (or export ZIP and upload to GitHub).
  2. On GitHub, go to Settings ➔ Pages (in the left sidebar).
  3. Under Branch, choose main and folder / (root), then click Save.
# Or push via Git CLI:
git remote add origin https://github.com/DeltaGaming07/TempTracker.git
git branch -M main
git push -u origin main

✓ Your live web app URL will be: https://DeltaGaming07.github.io/TempTracker/
